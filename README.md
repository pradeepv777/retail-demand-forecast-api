# Retail Demand Forecasting and Promotion Impact Analysis

## Project Overview

This project analyzes retail sales data to understand sales patterns, promotional effects, holiday behavior, and store-level characteristics.

The project will also develop and compare classical time series forecasting and machine learning approaches.

## Project Structure

- `01_eda.ipynb` - Exploratory data analysis
- `02_forecasting_classical.ipynb` - Classical forecasting models
- `03_forecasting_ml.ipynb` - Machine learning forecasting
- `04_promotion_analysis.ipynb` - Promotion impact analysis
